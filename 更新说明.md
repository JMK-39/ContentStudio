# Changelog

## Recipe Removal

- Simplified new removal rules to target either a final output item ID or one exact recipe ID.
- Apply rules to original datapack recipes before recipe scripts run. Recipes added later by KubeJS, CraftTweaker, or the ContentStudio editor are preserved.
- Added recipe type filtering. Item search still supports names, mod IDs, and tags.
- Existing mod, tag, and recipe type rules remain available for review and removal.

## Loot Editor

- Removed the duplicate selected loot table name and ID from the right panel.
- Moved the editing area upward to provide more room for content.

# 更新说明

## 配方移除

- 新建规则简化为按最终产物物品 ID 移除，或按单条配方 ID 移除。
- 移除规则在原始数据包配方进入配方管理器时应用。之后由 KubeJS、CraftTweaker 添加的配方，以及 ContentStudio 编辑器添加的配方都会保留。
- 配方列表增加按配方类型筛选；物品搜索继续支持名称、模组 ID 和标签。
- 旧配置中的模组、标签和配方类型规则仍可查看和撤销。

## 战利品编辑器

- 移除右侧重复显示的当前战利品表名称和 ID。
- 右侧编辑区域上移，增加内容显示空间。
