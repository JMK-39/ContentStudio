# ContentStudio 多版本迁移设计

沿用用户已指定的核心架构与前序附属迁移方案。启用 Forge 1.20.1 和 NeoForge 1.21.1，26.1.2 仅预留，等待 Claude 完成核心修复。Java 21、Gradle 9.8、Stonecutter、MDG；构建全部启用节点，输出 <modid>-<loader>-<mc>-<version>.jar。

保留 Forge 玩法、配置、语言、资源和既有修改；通过原有 JUnit 测试及旧 JAR 指令对比验证。1.20.1 不启动游戏。1.21.1 原生物品组件，不接受或转换旧物品 NBT；世界/实体持久化仍用原生 NBT。配方、战利品、村民交易和工具提示保持原有功能与权限。JEI 使用现有本地依赖。

在用户指定目录的迁移分支执行，保留 IDE 与兄弟核心路径；已有修改与 JAR 基线先备份。使用现有 PCL2 1.21.1 客户端验证，不改内存、不单独下载客户端，不改核心仓库。每个仓库独立本地提交，不推送发布。
