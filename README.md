# Content Studio

> V1.0

## 简体中文

在游戏内可视化制作和管理配方、战利品、村民交易与物品提示。

### 核心功能

- 创建、预览和移除工作台及多种加工配方。
- 编辑实体、方块和容器战利品，包括掉落池、权重和移除规则。
- 按职业、等级维护村民交易，并管理流浪商人交易；支持村民 AI 与诱导跟随相关设置。
- 按物品及 NBT 设置 Tooltip，支持普通、Shift 和 Alt 显示模式。

### 使用

按 **F6** 进入 Content Studio，选择所需编辑器。配方、交易和战利品属于服务器公共数据，保存需要相应管理权限。

### 前置依赖

必需：Forge 47.4.2+、KineticCore 26.9.20+；可选：JEI 15.20+、EMI、REI。

## English

Visually creates and manages recipes, loot, villager trades, and item tooltips in-game.

### Features

- Create, preview, and remove crafting and processing recipes.
- Edit entity, block, and container loot pools, weights, and removal rules.
- Manage villager trades by profession and level, wandering-trader trades, and villager AI/lure settings.
- Set item- and NBT-based tooltips with normal, Shift, and Alt display modes.

### Usage

Press **F6**, select Content Studio, and open an editor. Recipes, trades, and loot are shared server data; saving requires appropriate administrator permission.

### Requirements

Required: Forge 47.4.2+, KineticCore 26.9.20+. Optional: JEI 15.20+, EMI, REI.
